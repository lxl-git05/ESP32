| ---- | ------- | ---------- | ------------------------ |
| D0   | GPIO1   | I2C_SCL    | 这么配置是为了方便面包板 |
| D1   | GPIO2   | I2C_SDA    | 记得别搞反了             |
| D2   | GPIO3   | AIN1       | PWM1: 右边               |
| D3   | GPIO4   | BIN1       | PWM2: 左边               |
| D4   | GPIO5   | Encoder_A+ |                          |
| D5   | GPIO6   | Encoder_A- |                          |
| D6   | GPIO43  | AIN2       | 备用摄像头的两个引脚     |
| D7   | GPIO44  | BIN2       | 备用摄像头的两个引脚     |
| D8   | GPIO7   | Encoder_B+ |                          |
| D9   | GPIO8   | Encoder_B- |                          |
| D10  | GPIO9   | D10        |                          |
|      | GPIO21  | 板载LED    |                          |
